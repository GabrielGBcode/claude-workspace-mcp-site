Privacy Policy — Claude Workspace MCP

Last updated: November 22, 2026

Who uses this app

Claude Workspace MCP is a personal tool used only by its owner, with Google accounts that belong to the owner. It is not offered to other people.

What data is accessed

With the account holder's consent, the app accesses Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Slides data of the authorized accounts, only to carry out actions the owner requests.

Where data is stored

OAuth tokens are stored only on the owner's own computer. The app has no server and keeps no copy of Google user data anywhere else.

Sharing

Google user data is not sold, not shared with third parties and not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also removes all stored access.
